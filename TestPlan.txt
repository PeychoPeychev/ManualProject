Objective

The objective of this testing effort is to validate that the core e-commerce functionality of the Sauce Demo Shopify website works correctly across desktop and mobile devices.
The testing ensures that users can successfully:

- browse products
- add and remove products from the cart
- proceed to checkout
- interact with primary navigation and UI elements on both desktop and mobile environments.

2. Scope
2.1 In Scope
Desktop Web:

- Product catalog functionality
- Cart operations (add/remove/update)
- Checkout navigation
- Main navigation and UI elements

Mobile Web:

- Responsive layout on mobile devices
- Product catalog usability on small screens
- Cart behavior on mobile
- Mobile checkout navigation
- Mobile menu (hamburger menu, if available)
- Touch interactions (tap instead of click)

2.2 Out of Scope

- Native mobile applications (iOS / Android apps)
- Mobile performance testing
- Payment processing
- Email notifications
- Backend / API testing

Security testing

3. Test Approach
3.1 Test Levels

- Smoke Testing: Validation of critical user flows on desktop and mobile
- Regression Testing: Detailed verification of functionality and UI behavior
- Responsive Testing: Layout and usability validation across different screen sizes
- Negative Testing: Validation of system behavior during invalid or unexpected user actions

3.2 Test Types

- Functional testing
- UI and UX testing
- Responsive testing
- Exploratory testing (limited)

5. Entry and Exit Criteria
5.1 Entry Criteria

Testing can begin when:

- the website is accessible on desktop and mobile
- main pages load correctly
- no known blocking incidents exist

5.2 Exit Criteria

Testing is considered complete when:

- all Smoke test cases pass on desktop and mobile
- no open Blocker defects remain
- test results are documented in the Test Summary Report

7. Risks and Mitigation

8. Assumptions and Dependencies

- The website is a demo Shopify store
- Mobile testing is limited to mobile web (not native apps)
- Some mobile behaviors depend on browser rendering
- Test data may change without notice
