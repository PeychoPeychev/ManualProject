QA Manual Portfolio
Sauce Demo Shopify – Manual Testing Project
Project Overview

This repository contains a manual QA testing portfolio project created for the demo e-commerce website:

🔗 https://sauce-demo.myshopify.com/

The purpose of this project is to demonstrate manual testing skills, including:

test planning

test case design

bug reporting

test execution summary

desktop and mobile web testing

The project follows a real-world QA workflow and is suitable for junior / mid QA roles and freelance work.

Testing Scope

The testing covers the core e-commerce functionality of the website:
Product catalog
Cart functionality
Checkout button behavior
Responsive behavior on mobile devices
Basic UI and usability checks

Out of Scope

Payment processing
User authentication
Email notifications
Backend / API testing
Performance and security testing

Types of Testing Performed

Manual Functional Testing
Smoke Testing
Regression Testing
Negative Testing
Mobile Web Testing (Responsive & Touch interactions)

Documentation Description

TestPlan.md
Defines the overall testing strategy, scope, test approach, environments, risks, and mobile testing considerations.

TestCases.md
Contains detailed positive and negative test cases for:
Desktop web
Mobile web
Each test case includes priority, type, steps, and expected results.

BugReports.md

Includes a structured bug report template and sample defects with:
severity
priority
clear reproduction steps
expected vs actual results

TestSummary.md

Provides a summary of the test execution results, defect analysis, risks, and release recommendation.

Desktop & Mobile Testing

The project includes testing for:

Desktop browsers (Chrome)
Mobile devices (iOS & Android)
Responsive layouts
Touch interactions and orientation changes
Mobile testing was performed using:
real device scenarios
browser developer tools (responsive mode)
