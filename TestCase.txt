Sauce Demo Shopify – Desktop & Mobile Web

DESKTOP – POSITIVE TEST CASES

TC-001 – Load Homepage (Desktop)
Priority: P0
Type: Smoke
Preconditions: User has an active internet connection

Steps:
Open a web browser (Chrome)
Navigate to https://sauce-demo.myshopify.com/

Expected Result:
Homepage loads successfully
Product list is displayed


TC-002 – Display Product Information (Desktop)
Priority: P0
Type: Smoke
Preconditions: Homepage is loaded

Steps:
Review the product cards on the homepage

Expected Result:
Each product displays name, price, and image

TC-003 – Add Product to Cart (Desktop)
Priority: P0
Type: Smoke
Preconditions: Products are visible on the page

Steps:

Click “Add to cart” on any product

Expected Result:
Product is added to the cart
Cart icon updates with item count

TC-004 – Remove Product from Cart (Desktop)
Priority: P1
Type: Regression
Preconditions: A product is already added to the cart

Steps:
Open the cart
Click “Remove”

Expected Result:
Product is removed
Cart becomes empty

TC-005 – Checkout Button Availability (Desktop)
Priority: P1
Type: Regression
Preconditions: Cart contains at least one product

Steps:
Open the cart

Expected Result:
“Checkout” button is visible and enabled

DESKTOP – NEGATIVE TEST CASES

TC-009 – Open Cart with Empty Cart (Desktop)
Priority: P1
Type: Negative
Preconditions: No products added to cart

Steps:
Open the cart

Expected Result:
Empty cart state is displayed
No UI errors or crashes occur

TC-010 – Attempt Checkout with Empty Cart (Desktop)
Priority: P1
Type: Negative
Preconditions: Cart is empty

Steps:
Open the cart
Click “Checkout” (if available)

Expected Result:
Checkout is blocked or a validation message is shown
User cannot proceed without products

TC-011 – Rapid Click on “Add to cart” (Desktop)
Priority: P1
Type: Negative / Edge
Preconditions: Products are visible

Steps:
Click “Add to cart” multiple times quickly

Expected Result:
Only one item is added (or behavior is clearly defined)
No UI glitches or incorrect cart count

TC-012 – Refresh Page After Adding Product (Desktop)
Priority: P2
Type: Negative / Session
Preconditions: Product is added to cart

Steps:
Add a product to the cart
Refresh the page
Open the cart

Expected Result:
Cart state is consistent (item persists or resets predictably)
No broken UI or errors
